# Amazon Sales Data Cleaning & Data Quality Analysis

## Project Overview

This project focuses on cleaning, validating, and preparing an Amazon e-commerce sales dataset for further analysis.

The dataset contains order, product, sales, customer location, fulfilment, quantity, and payment-related information. The project demonstrates how Python and Pandas can be used to identify and resolve common data-quality issues in a real-world dataset.

## Objectives

* Inspect the structure and quality of the dataset
* Identify duplicate records
* Analyze missing values
* Clean and standardize text data
* Convert and validate date and numerical columns
* Standardize categorical and location values
* Validate the cleaned dataset
* Generate a before-and-after data quality report
* Export the cleaned dataset for further analysis

## Tools & Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook
* CSV / Excel

## Data Cleaning Process

The following steps were performed:

1. Imported and inspected the dataset
2. Checked dataset dimensions and data types
3. Analyzed missing values
4. Checked for duplicate records
5. Standardized column names
6. Cleaned text and categorical values
7. Converted date columns into appropriate date format
8. Validated numerical columns such as quantity and amount
9. Standardized location-related values
10. Performed post-cleaning validation
11. Generated a data quality report
12. Exported the cleaned dataset

## Data Quality Validation

The cleaned dataset was checked for:

* Duplicate rows
* Duplicate Order IDs
* Missing values
* Negative quantities
* Negative amounts
* Incorrect data types
* Invalid dates
* Inconsistent categorical values
